# Путешествие McK Partners — страница-приглашение

Самодостаточная одностраничная страница с многошаговой формой регистрации
в стиле Google Forms. Один файл `index.html` — CSS и JS внутри, сборка не нужна.

## Структура

```
mck-retreat/
├── index.html        ← сама страница (весь CSS и JS внутри)
├── assets/           ← фото поездки (в т.ч. og-коллаж), логотип (SVG), фавикон
│   └── trip/         ← 8 фотографий поездки (towers, пляж, лобби, яхта…)
└── README.md
```

## Что на странице

1. **Герой** — логотип McK Partners, заголовок «Приглашаем Вас в путешествие McK Partners»,
   подзаголовок, кнопка «Заполнить форму» (плавный скролл к форме).
   На титуле — фото вечерних башен Etihad Towers (`assets/trip/towers.jpg`).
2. **О путешествии** — «Дорогие друзья, … Нашей доброй традицией стали
   совместные путешествия…», «Дата: 15-18 октября»; текст узкой колонкой
   слева, справа — фото лобби (лестницы с красными коврами, люстры) с чипом
   «Отель: The St. Regis Abu Dhabi» (в стиле чипа героя, ссылка на Marriott);
   на мобильном фото стоит под текстом.
3. **Программа путешествия** — по дням (15–18.10) + галерея из 6 фото во всю
   ширину одним «окном»: вертикальные по краям, в центре полугоризонтальные,
   ряды выровнены по горизонтали (верх ровный, зазоры уходят вниз); обрезка
   ≤15% (`assets/trip/`).
4. **Форма** — заголовок «Приглашение» + подпись «Просим Вас уделить несколько
    минут и подтвердить свое участие в путешествии»; по умолчанию **скрыта целиком**
    и раскрывается только при выборе «Участие в путешествии: Да» (карточка-гейт `#choiceCard`):
   - карточка 1 «Путешествие»: Фамилия/Имя*, город вылета* (вариант «Другое» → поле «Название города»*), выбор рейса*,
     «Комментарии» с подсказкой про вылет раньше/позже;
   - карточка 2 «Данные заграничного паспорта» — раскрытый блок формы:
     имя латиницей*, серия/номер*, даты*, орган выдачи*.

Логика: «Да» → плавно раскрывается вся форма и прогресс-бар (шаг 1 из 2,
переход на шаг 2 — при фокусе в блоке паспорта);
«Нет» → сообщение «Спасибо за Ваш ответ!»;
«Очистить форму» → сброс полей, ошибок и закрытие формы обратно к гейту.

Фотографии страницы — только собственные (`assets/trip/`, 8 шт.);
сторонние стоки (Unsplash и т.п.) не используются.

## Настройка отправки данных

В конце `index.html` есть одна строка-константа:

```js
const LEAD_ENDPOINT = '';
```

- `''` (по умолчанию) — **демо-режим**: форма показывает «Спасибо!», а данные
  выводятся в консоль браузера (`F12` → Console). Удобно для проверки.
- `'/api/lead'` — отправка POST-запросом `FormData` (multipart) на ваш эндпоинт.
- Можно указать URL вебхука: Telegram-бот, Make/Zapier → Google Sheets, n8n.

Пример для Telegram-бота через вебхук-посредника:

```js
const LEAD_ENDPOINT = 'https://hook.eu2.make.com/xxxx-xxxx';
```

Отправляется `FormData` (поля формы), сервер/вебхук должен принимать
multipart/form-data.
При ошибке сети показывается сообщение «Не удалось отправить форму…»,
кнопка снова становится активной.

## Публикация на Tilda

1. **Через HTML-блок** (T123): Настройки сайта → Файлы → загрузите `index.html`
   как статическую страницу, либо вставьте содержимое в блок «HTML»
   (для вставки кода страницы целиком лучше подходит *Свойства блока →
   «HTML-код»* на пустой странице).
2. **Через «Свои домены / Статический сайт»**: Tilda позволяет отдать
   произвольный `index.html` как корневую страницу проекта.
3. Файлы `assets/` необязательны — логотип встроен в HTML в виде inline-SVG
   (два варианта: синий `#003a7e` для бежевого фона, белый — для футера).
   Фотографии лежат в `assets/trip/`, шрифты грузятся с CDN Google Fonts,
   поэтому без папки `assets/` работают только тексты и шрифты.

## Доступность и SEO

- `lang="ru"`, мета-заголовок/описание, og:/twitter:-теги с og-коллажем
  (`assets/trip/collage.jpg`), фавикон и `theme-color` McK Partners.
- Метки `<label for>`, `aria-required`, `aria-describedby`, ошибки с `role="alert"`,
  прогресс-бар с `role="progressbar"`, skip-link «Перейти к форме».
- Учтён `prefers-reduced-motion` (отключаются анимации), кольца фокуса `:focus-visible`.
- Адаптив: десктоп / планшет / смартфон (одна колонка, кнопки во всю ширину).
